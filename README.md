# Airspace Awareness

A comprehensive airspace awareness system combining real-time aircraft detection, remote ID tracking, and airspace management.

## Features

- **Multi-Source Capture**: WiFi, Bluetooth, ADS-B, and GPS
- **Remote ID Support**: ASTM F3411 decoder
- **Fusion Engine**: Track management and data fusion
- **Airspace Management**: Geofencing, FRZ generation, NOTAM integration
- **GUI**: Kivy-based map interface
- **Tile Management**: Hybrid online/offline tile sourcing
